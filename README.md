# Real-time Network Intrusion Detection System (IDS) using Machine Learning

This project implements a Machine Learning-based Network Intrusion Detection System (IDS) using the **CIC-IDS2017** dataset. The system is designed to classify network traffic as `BENIGN` (normal) or various types of attacks (such as `DDoS`, `PortScan`, `Web attacks`, etc.).

The pipeline is structured as **Jupyter Notebooks**, making it easy to run on **Google Colab**, **Kaggle**, or a Local environment.

## 📁 Project Structure

```text
├── datasets/                   # Directory for CIC-IDS2017 CSV files (Ignored by Git)
├── models/                     # Saved models (.pkl), scalers, and label encoders
├── notebooks/                  # Main Jupyter Notebooks
│   ├── 01_Data_Prep_and_EDA.ipynb
│   ├── 02_Feature_Engineering_and_Modeling.ipynb
│   └── 03_Simulation_and_Deployment.ipynb
├── requirements.txt            # Required Python libraries
├── alerts.log                  # Log file for attack detection (generated by nb 03)
└── README.md                   # Project documentation
```

## 🚀 Setup Instructions

### 1. Prerequisites
Install the required libraries using pip:
```bash
pip install -r requirements.txt
```

### 2. Download the Dataset
The dataset files are too large to be hosted on GitHub. Please download the **CIC-IDS2017** dataset from Kaggle:

1.  Visit: [Kaggle Network Intrusion Dataset (CIC-IDS2017)](https://www.kaggle.com/datasets/chethuhn/network-intrusion-dataset/data)
2.  Download the ZIP file and extract it.
3.  Place the extracted `.csv` files into the `datasets/` folder of this project.

The following files are expected in the `datasets/` folder:
- `Friday-WorkingHours-Afternoon-DDos.pcap_ISCX.csv`
- `Friday-WorkingHours-Afternoon-PortScan.pcap_ISCX.csv`
- `Friday-WorkingHours-Morning.pcap_ISCX.csv`
- `Monday-WorkingHours.pcap_ISCX.csv`
- `Thursday-WorkingHours-Afternoon-Infilteration.pcap_ISCX.csv`
- `Thursday-WorkingHours-Morning-WebAttacks.pcap_ISCX.csv`
- `Tuesday-WorkingHours.pcap_ISCX.csv`
- `Wednesday-workingHours.pcap_ISCX.csv`

## 🛠️ Usage Pipeline

### Step 1: Data Preparation & EDA
Run `notebooks/01_Data_Prep_and_EDA.ipynb` to:
- Load raw CSV files.
- Clean data (handling NaNs and Inf values).
- Perform Exploratory Data Analysis.
- Save the cleaned data to a Parquet file for efficiency.

### Step 2: Feature Engineering & Modeling
Run `notebooks/02_Feature_Engineering_and_Modeling.ipynb` to:
- Extract relevant features.
- Handle class imbalance using **SMOTE**.
- Train a **Random Forest Classifier**.
- Save the trained model and preprocessing objects.

### Step 3: Simulation & Deployment
Run `notebooks/03_Simulation_and_Deployment.ipynb` to:
- Simulate real-time network traffic.
- Detect intrusions using the trained model.
- Log alerts to `alerts.log`.

## 📊 Dataset Information
The **CIC-IDS2017** dataset contains benign and the most up-to-date common attacks, which resembles the real-world data (PCAPs). It includes network traffic analysis results using CICFlowMeter with labeled flows based on the time, source and destination IPs, source and destination ports, protocols and attacks.
